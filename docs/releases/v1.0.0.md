# KohdaLab SLM v1.0.0

Release preparation / 公開準備中。No v1.0.0 binaries have been published yet.

## Features / 機能

- Uniform, Single Wave, Multi-Wave and one-axis Sweep patterns with px, µm and µm⁻¹ units.
- Persistent pattern list: keyboard navigation, optional automatic apply, multiple selection, drag reorder and removal Undo.
- Grayscale, Rainbow and Viridis previews; CSV/PNG output and background experiment export with manifests.
- Settings drafts, protected configuration/list saves, session logs and guarded shutdown.
- Windows HDMI/DVI output for Santec SLM-200; USB wavelength setting through the separately installed manufacturer SDK. Maximum-phase settings are read back rather than guessed.

パターン生成、常時表示リスト、上下キー操作、自動適用、複数選択・並べ替え・削除の取り消し、3種のカラーマップ、CSV/PNG保存、バックグラウンド書き出しに対応します。

## Platforms and prerequisites / 動作環境

- Windows x64: Santec display output implementation; manufacturer SDK required for USB wavelength control. No vendor SDK binaries are bundled.
- macOS Apple Silicon: pattern editing, export and simulated output. Physical SLM output is not implemented on macOS.
- Build from source with Rust 1.99.1 using `cargo build --release --locked`.
- Default configuration: `~/.kohdalab/slm/config/config.json` (Windows: `%USERPROFILE%\.kohdalab\slm\config\config.json`). Existing configurations and experiment data must be preserved.

Windowsは実機出力、Macは編集・書き出しとシミュレーションが対象です。USB波長設定にはメーカーSDKが別途必要です。

## Verification and limitations / 検証範囲

Local tests, formatting, Clippy and compiled simulation results are recorded in `docs/releases/v1.0.0-validation.md`. These do not establish optical performance or native Windows package qualification.

The earlier clione bench test confirmed desktop readback of a 200 px pattern. It did not qualify this complete v1.0.0 source, optical phase calibration, wavelength changes, display-power transitions or SDK timeout recovery. Recheck these on hardware before measurement. Thorlabs hardware is not qualified. Fable review is deferred.

以前のclione試験では200 pxパターンのデスクトップ読み戻しを確認しましたが、今回の版の実機試験・光学位相・波長校正は未完了です。Fableレビューも未実施です。
